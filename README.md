# Teclado como ratón

Aplicación ligera para Windows que permite controlar el puntero con el teclado.

## Uso

- `Ctrl+Alt+M`: activar o desactivar el modo ratón.
- Flechas o teclado numérico `8/4/6/2`: mover el puntero.
- `Z`: clic izquierdo.
- `.`: clic derecho.
- `Retroceso`: volver al teclado normal sin cerrar la aplicación.
- La velocidad se configura en la ventana; `Ctrl+Alt+PageUp/PageDown` la ajusta en pasos de 5.

La versión publicada es nativa para Windows y no depende de Python.
