# Teclado como ratón

Aplicación ligera para Windows que permite controlar el puntero con el teclado.

## Uso

- `Ctrl+Alt+X`: activar o desactivar el modo ratón.
- Flechas o teclado numérico `8/4/6/2`: mover el puntero.
- Mantén `X` y pulsa `↑`/`↓` para hacer scroll arriba/abajo, o `←`/`→` para scroll horizontal.
- `Z` o `NumPad 1`: clic izquierdo; mantén la tecla pulsada mientras mueves las flechas para arrastrar o cambiar el tamaño de una ventana.
- `.` o `NumPad 3`: clic derecho.
- `B`: volver a la página anterior; `N`: avanzar a la página siguiente en el navegador.
- `Retroceso`: volver al teclado normal sin cerrar la aplicación.
- La velocidad se configura en la ventana; `Ctrl+Alt+PageUp/PageDown` la ajusta en pasos de 5.

La versión publicada es nativa para Windows y no depende de Python.
